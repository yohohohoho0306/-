# 月次の自動実行の設定

Claude Code のルーチン（定期実行）で、毎月の判定を自動で始めるための設定。2026-10-15 に利用者が決めた内容。

## 設定

| 項目 | 値 |
|---|---|
| 実行日 | 毎月14日。14日が土日・祝日（東証の休業日）なら、その前の営業日（多くは金曜日） |
| 起動 | 毎月10〜14日の朝 7:53（日本時間）。cron は `CRON_TZ=Asia/Tokyo 53 7 10-14 * *`。毎回 `tools/ricky_report/run_day.py` で実行日かを確かめ、違う日はすぐ終える（月に4回ほど、短い起動が空振りする） |
| セッション | 起動のたびに新しいセッション（前回の会話は持ち越さない。続きはリポジトリのノートから読む） |
| 作業環境 | Claude Code のクラウド環境「Default」（EDINET・Yahoo Finance に届き、EDINET_API_KEY が入っている環境） |
| リポジトリ | yohohohoho0306/-（既定のブランチから始まる） |
| 調べる範囲 | 通過したすべての銘柄と、確認済みでない不通過銘柄 |
| 有報のキャッシュ | ブランチ `claude/data-cache` に圧縮して保存（約16MB。保存のたびに古いデータは消える） |
| 結果 | `research/runs/<日付>.md`（月次の要約）と銘柄ノート。既定のブランチへのプルリクエストを作り、スクリプトを変えていなければマージする |

8時ちょうどではなく 7:53 にしたのは、ちょうどの時刻は起動が混み合って遅れることがあるため。東証の取引開始（9時）より前なので、株価は前の営業日の終値になる。

## ルーチンに渡す文面

```text
ultracode
Ricky流の増配株スクリーニングの月次の実行です。リポジトリの research/monthly-routine.md と research/next-run.md を読んでから、次のとおり進めてください。

1. pip install -r requirements.txt pytest pypdf のあと python tools/ricky_report/run_day.py を実行する。結果が「skip」なら、ほかに何もせず「今日は実行日ではない（今月の実行日は …）」とだけ報告して終える。
2. 「run」なら、research/next-run.md の「月次の実行」を、基準日＝今日（日本時間）で最後まで進める。最初に python tools/ricky_report/cache_sync.py restore、最後に python tools/ricky_report/cache_sync.py save --as-of <今日> を実行する。調べる範囲は通過したすべての銘柄（新しく通過した銘柄も、続けて通過した銘柄も）と、確認済みでない不通過銘柄。
3. 結果を research/ に残してコミットし、プッシュして、既定のブランチへのプルリクエストを作る。テストが通り、スクリプト（jpstock/・tools/）を変更していなければ、そのプルリクエストをマージする。スクリプトを変更した場合はマージせず、何を直したかを報告する。
4. 最後に、新しく通過・脱落・印の変化・境界に近い銘柄・テーマ性や配当方針の表記を変えた銘柄を短く報告する。

守ること：EDINET_API_KEY は設定済みかどうかだけ確かめ、値は表示しない。数値は推測で埋めず、確認できないものは「未確認」と書く。売買の推奨はしない。
```

## プロジェクト（claude.ai/code の Projects）に入れるとき

プロジェクトの指示に次を書いておくと、プロジェクトの中の会話（月次の実行も、結果についての相談も）で毎回説明しなくてよい。

```text
このプロジェクトは Ricky流の増配株スクリーニング（EDINET の有報と Yahoo Finance の株価で上場会社全体に当てはめる）。
作業の前に research/INDEX.md と research/next-run.md を読む。月次の実行は research/next-run.md の「月次の実行」に従う。
EDINET_API_KEY は設定済みかどうかだけ確かめ、値は表示しない。数値は推測で埋めず、確認できないものは「未確認」と書く。売買の推奨はしない。
```

- プロジェクトの作業環境は「Default」にする（EDINET・Yahoo に届かない環境では判定できない）。
- プロジェクトの中の会話は、既定で上位のモデル・高い推論設定で動くので、プランの利用枠を早く使う。

## 変えたいとき

- 範囲を「新しく通過した銘柄だけ」にする：上の文面の 2 の範囲を書き換え、[次回の進め方](next-run.md) の「月次の実行」の最後の段落のオプションを使うよう書く。
- 日時を変える：ルーチンの cron と、`tools/ricky_report/run_day.py` の `DAY`（14日）を変える。
- 止める：claude.ai/code のルーチンの画面で止める（または Claude に「Ricky流スクリーニングの月次のルーチンを止めて」と頼む）。
